This guide is kept up to date with the website. It opens for reading. Use **Edit**, then **Save**, to correct the article. If something no longer matches the site, ask the person who manages the website.

Open **Portfolio** in the left menu to add or edit a project. Each project is its own page on the site.

To add one, create a new Portfolio item. Tina asks for a file name before the form opens. That file name becomes the web address: a file named `wawa-hatfield` is published at `/portfolio/wawa-hatfield`. Use a short, lowercase name with hyphens, and avoid changing it later, because the address will change with it. The **Title** is separate, and it is the name visitors see.

## What visitors see

The project page opens with the cover image across the full width of the window, the same kind of banner a service page uses. Under the image are the Home / Portfolio links, then the title. The written body follows, with a **Project Details** box beside it when any of those details are filled in. A client, architect, engineer, or contractor is shown by name. If that party has a logo, a small logo sits beside the name. If that party has a website, the name links to it and opens in a new tab. Content cards, the photo gallery, quotes, and videos come after the writeup. Sector and service labels appear as links at the bottom of the page.

Project cards on the Portfolio page and on the homepage use the title, the short description, the cover image, and the date.

## The fields

- **Title** is the project name. It is the page heading and the name on cards.
- **Description** is the short summary. It appears on project cards, in the homepage slideshow, and as the preview text when the page is shared. See **Search engines and AI**.
- **Location** and **Date** appear in the Project Details box. Date can be a year, such as 2020, or a longer date.
- **Client**, **Architect**, **Engineer**, and **Contractor** also appear in that box. Each one lists parties from **Entities**. Search for a party that already exists, or choose **Add new entity** to create one without leaving the project. A new entity asks for **Name**, **Kind** (Person, Company, or Organization), an optional **Website**, and an optional **Logo**. Upload the logo from the media library. See **Photos, videos, and content cards**. You can list more than one party on a line. Use **Up** and **Down** to change their order, and **Remove** to take one off. The same party can be used on many projects, and on more than one of these lines. Visitors see the name. A logo shows beside the name when one is set. A website turns the name into a link that opens in a new tab. Leave a line empty to hide it. In the visual editor, click a party in the Project Details box to edit that entity's name, kind, website, and logo. The back arrow returns to the project, even when nothing was changed. Open **Entities** in the left menu to edit a party on its own. That back arrow returns to the list of entities. A change to a party shows on every project that uses it.
- **Project Cost** and **Size** appear in that same box. Examples: `$145M` and `166,000 SF`. Leave a field blank to hide that line.
- **Hero / cover image** is the full-width photo at the top of the project page. Under it, visitors see the Home / Portfolio links, then the title. It is also required if you want the project in the homepage slideshow. Upload it from the media library. See **Photos, videos, and content cards**.
- **Gallery** is the set of photos lower on the page. Visitors can open a photo larger, move between photos by swiping or with the arrows, and close it with the X at the bottom right, the Escape key, or a click beside the photo. The expand button next to the X switches between the full width of the photo and filling the height of the screen. They can drag to look around a photo that is larger than the screen, and pinch to zoom in. Swiping past the edge of that photo moves to the next or previous one. Each image can have **Alt text** (a short description of the photo, also shown along the bottom of the large photo), an optional **Link URL** (for example, to send someone to another project), and an optional **Link button label**. If you leave the gallery empty but set a cover image, the cover image is shown in the gallery instead.
- **Customer Quotes** are testimonials on this project. **Quote** is the words, **Author** is the person's name, and **Role / Company** is their title or organization. Turn on **Promote to home page** to also show that quote on the homepage. Every quote on every project is listed on the Testimonials page, whether or not it is promoted.
- **Sectors** and **Services** are checklists. Check every sector and service that applies. Those choices link the project to the matching pages, include it in their project lists, and show up as links at the bottom of the project page. The choices come from **Tags**. A tag you create there shows up in these lists right away. See **Sectors, services, and tags**.
- **Order** controls where the project sits in lists. A smaller number appears first. On the Portfolio page, a blank Order is treated as 0, so those projects group at the front. On the homepage Latest projects section, a blank Order is placed last.
- **Featured** puts the project in the homepage hero when **Show featured projects** is on under **Hero** on **Home**. It also needs a cover image. **Hero order** sets where it sits among the other featured projects. A smaller number comes first. Leave **Hero order** blank to place the project after every numbered project. Whether projects come before slides or tags is the **Order** list on **Home**. **Hero order** does not change **Order**. How many slides the hero shows is set on **Home**. See **Home page**.
- **Videos** are YouTube clips on this project page. See **Photos, videos, and content cards**.
- **Content Cards** are promotional blocks under the writeup and above the gallery. See **Photos, videos, and content cards**.
- **Body** is the main writeup. You can use headings, bold text, lists, and links.

Drag items in a list, such as gallery photos or quotes, to change their order. Use the list controls to add or remove one.
