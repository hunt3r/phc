# Examples from past runs

Each example lists the item, the imagery decided on before searching, the queries used, and
what the user picked. The picks show the house taste: real work scenes and literal objects
with clear subjects over generic office stock.

| Item | Ideal imagery | Queries | Pick |
|---|---|---|---|
| Project Schedule Management | Gantt chart or schedule on paper, site progress | gantt chart, construction schedule, project timeline, calendar deadline | Gantt-style printout with pen (Pixabay) |
| Project Schedule (pre-construction) | Planning board, calendar, critical-path sketch | planning timeline wall, roadmap sticky notes, flowchart diagram | Calendar with red pins (Unsplash) |
| Remediation | Crews in protective suits, contaminated soil excavation | soil remediation, hazmat suit worker, excavator contaminated soil; Wikimedia "superfund cleanup" | EPA crew in Tyvek sampling debris (Wikimedia, public domain) |
| Requests for Information | Redlined drawings, field questions on plans | construction drawings markup, marking blueprint red pen | Hands on a red-marked floor plan (Pexels) |
| RFP Development | Bid documents, binders, specifications | proposal document, binders office, contract documents | Binders packed with documents (Pexels) |
| Schematic Design / DD | Architectural models, elevation sets, trace sketches | architect sketching, architectural model, architectural drawing elevation | Site model with landscaping (Pixabay) |
| Special Construction Design Coordination | MEP coordination, BIM model, ductwork | mechanical room pipes, ductwork ceiling, engineer bim 3d model | Engineer working in a 3D model (Pexels) |
| Testing Agency Coordination | First round: slump tests and gauges. User asked for "more schedule oriented." | Second round: construction calendar schedule, inspection checklist, worker phone call | Writing on a desk calendar (Pexels) |
| Utility Service Coordination | Water, sewer, gas, and electric services | utility meters, gas meter, pipe installation trench | Electric, gas, and telecom meters on brick (Pexels) |

## Lessons

- When the description stresses scheduling or coordination, offer some calendar, phone,
  or checklist scenes, not just the technical activity.
- Two related tags (Utility Coordination and Utility Service Coordination) can share one
  search. Rank separately and give each its own image.
- When a user says "there's no tag for X", check for a `[no order]` legacy stub before
  continuing.
